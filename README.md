# Nice airport to the Pays de Fayence and the Dracénie

This repository hosts a one-page guide to private VTC transfers from Nice Côte d'Azur airport (NCE) to Montauroux, Fayence, Seillans, Draguignan, Flayosc and Lorgues, built from the fares published on [https://taxiaeroportnice.com](https://taxiaeroportnice.com/) and checked on 20 November 2026; the page is plain HTML with inline CSS and no scripts, so it can be served directly by GitHub Pages from the repository root.
